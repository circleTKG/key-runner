HOW TO PLAY

遊び方

迷路を進み、赤い扉を開けて、光るゲートを目指しましょう。

  1. 移動と向きW / ↑ で前進、A / ← で左を向き、D / → で右を向きます。A・D はその場で向きを変える操作です。後退キーはありません。
  2. 扉を開ける赤い扉に近づくと単語と入力欄が表示され、入力欄にカーソルが移ります。単語を入力して Enter を押してください。大文字・小文字は区別されません。
  3. 入力を間違えたら不正解でも入力し直せますが、難易度に応じて残り時間が減ります。チュートリアルでは時間のペナルティはありません。
  4. マップと表示マップの矢印は自分の位置と向き、赤いマスは未解除の扉、ゴールのマスは脱出地点です。激むずでは周囲だけが表示されます。残り時間とスコアは画面上部で確認できます。
  5. スコアを獲得する単語を正解すると扉が開き、スコアが250加算されます。すべての扉を開ける必要はありません。
  6. ゴールを目指す残り時間がなくなる前に、迷路の奥にある光る脱出ゲートへ到達するとクリアです。
