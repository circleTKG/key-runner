      HOW TO PLAY

      遊び方

      このゲームは迷路ゲームです。キーボードのみでも遊ぶことができます。

      • WAD または矢印キーで移動します。
      • 赤い扉の近くで単語を入力し、Enter キーで扉を開きます。
      • 制限時間内に迷宮の奥にある脱出ゲートを目指します。

      FIRST RUN

      チュートリアル

      1. 歩くWASD または矢印キーで迷路を進みます。
      2. 扉を開ける赤い扉の近くで表示された単語を入力し、Enter を押します。
      3. 脱出するゴールの光るゲートへ到達するとクリアです。
